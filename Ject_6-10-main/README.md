# PROJECT - ระบบสั่งอาหารร้านอาหาร

โปรเจกต์นี้ปรับจาก `ject2` ตามหน้าจอใน `หน้าหลัก.pdf` และใช้รูปอาหารจาก `public/Pic` โดยตรง

## วิธีรัน
1. เปิด Terminal ในโฟลเดอร์นี้
2. รัน `npm install`
3. รัน `npm start`
4. เปิด `http://localhost:3000`

## หน้าระบบ
- ลูกค้า: `http://localhost:3000/?table=1` เปลี่ยนเลขโต๊ะได้ 1-16
- ครัว: `http://localhost:3000/kitchen`
- พนักงานบริการ: `http://localhost:3000/service`
- แคชเชียร์: `http://localhost:3000/cashier`

## Flow ที่ทำไว้
1. แคชเชียร์เริ่มต้นมีโต๊ะ 01-16 เป็น `ว่าง`
2. กด `เปลี่ยนสถานะโต๊ะ` ก่อน จึงจะสามารถกดโต๊ะเพื่อสลับ `ว่าง/ไม่ว่าง` ได้
3. ถ้าไม่ได้เปิดโหมดเปลี่ยนสถานะ การกดโต๊ะจะใช้ดู `ข้อมูลบิล`
4. ลูกค้าเลือกเมนูจากรูปใน `public/Pic`
5. Add-on แบบที่กำหนดให้เลือกหลายรายการสามารถติ๊กหลายรายการพร้อมกันได้
6. ยืนยันสั่งอาหาร -> ออเดอร์ถูกส่งเข้าครัว และโต๊ะเป็น `ไม่ว่าง`
7. ครัวกด `เสร็จสิ้น` บนหน้าจอหรือแท็บเล็ต -> ออเดอร์ออกจากหน้าครัวและไปหน้าพนักงานบริการ
8. พนักงานบริการกด `เสิร์ฟแล้ว` -> ออเดอร์ออกจากหน้าบริการ
9. แคชเชียร์ดูบิลของโต๊ะและกด `รับชำระเงิน`
10. ระบบคำนวณเงินทอนให้ทันที
11. `QR CODE` เป็นเพียงปุ่มเลือกช่องทาง ไม่ได้สร้าง/ตรวจ QR จริง
12. ยืนยันการชำระ -> บันทึกการรับเงิน, ปิดบิล และเปลี่ยนโต๊ะเป็น `ว่าง`
13. `พิมพ์ใบเสร็จ` เป็นปุ่มตัวอย่าง ยังไม่สั่งพิมพ์จริง

ฐานข้อมูล `food.db` จะถูกสร้างอัตโนมัติเมื่อรันครั้งแรก
