# ซากุระ — ระบบสั่งอาหารร้านอาหารญี่ปุ่น (ผ่านแท็บเล็ตบนโต๊ะ)

ระบบสั่งอาหารสำหรับร้านอาหาร ประกอบด้วยหน้าจอ 4 บทบาท: ลูกค้า (แท็บเล็ตบนโต๊ะ), ครัว, พนักงานบริการ, และแคชเชียร์

## วิธีรัน
1. เปิด Terminal ในโฟลเดอร์นี้
2. รัน `npm install`
3. รัน `npm start`
4. เปิด `http://localhost:3000`

## หน้าระบบ
- ลูกค้า: `http://localhost:3000/?table=1` (เปลี่ยนเลขโต๊ะได้ 1–16)
- ครัว: `http://localhost:3000/kitchen`
- พนักงานบริการ: `http://localhost:3000/service`
- แคชเชียร์: `http://localhost:3000/cashier`

## การตั้งค่าร้าน / พร้อมเพย์ (สำคัญ)
แก้ไขข้อมูลร้านและเบอร์พร้อมเพย์ได้ที่ด้านบนของ `index.js` ในตัวแปร `RESTAURANT`:
```js
const RESTAURANT = {
  name: "ซากุระ",
  nameEn: "SAKURA",
  tagline: "ร้านอาหารญี่ปุ่น",
  promptpay: "0812345678"   // << ใส่เบอร์พร้อมเพย์จริงของร้าน (มือถือ 10 หลัก หรือเลขบัตร/ผู้เสียภาษี 13 หลัก)
};
```
QR ที่หน้าชำระเงินจะถูกสร้างตาม "ยอดบิลจริง" อัตโนมัติ เมื่อใส่เบอร์พร้อมเพย์ของร้าน ลูกค้าสแกนจ่ายได้ทันทีด้วยแอปธนาคาร

## Flow การใช้งาน
1. แคชเชียร์เริ่มต้นมีโต๊ะ 01–16 สถานะ `ว่าง`
2. กด `เปลี่ยนสถานะโต๊ะ` → เลือกโต๊ะ → กด `ยืนยันการเปลี่ยนสถานะ` เพื่อสลับ `ว่าง/ไม่ว่าง`
3. หากไม่ได้เปิดโหมดเปลี่ยนสถานะ การกดโต๊ะจะเป็นการดู `ข้อมูลบิล`
4. ลูกค้าเลือกเมนู → ปรับ Add-on (เห็นราคารวมแบบเรียลไทม์) → กด `เพิ่มลงตะกร้า`
5. **เมื่อเพิ่มลงตะกร้าแล้ว ระบบจะกลับไปหน้าเมนูพร้อมแจ้งเตือน และมีแถบตะกร้าลอยให้กดไปชำระ** (สั่งต่อได้สะดวก)
6. กด `ยืนยันการสั่งอาหาร` → ออเดอร์เข้าครัว และโต๊ะเปลี่ยนเป็น `ไม่ว่าง`
7. ครัวเห็นออเดอร์พร้อม **เวลาที่สั่งและเวลาที่ผ่านไป** (รอเกิน 8 นาทีการ์ดเตือนสีส้ม, เกิน 15 นาทีสีแดง) → กด `เสร็จสิ้น → ส่งเสิร์ฟ`
8. พนักงานบริการเห็นอาหารพร้อมเสิร์ฟ (พร้อมเวลาสั่ง) → กด `เสิร์ฟแล้ว`
9. แคชเชียร์ดูบิลของโต๊ะ (แยกตามออเดอร์พร้อมเวลา) → กด `รับชำระเงิน`
10. เลือกช่องทาง:
    - **เงินสด**: กรอกเงินรับ (มีปุ่มด่วน พอดี/+100/+500/+1000) ระบบคำนวณเงินทอนทันที
    - **QR พร้อมเพย์**: แสดง QR ตามยอดบิลจริง จ่ายพอดีไม่มีเงินทอน
11. ยืนยันการชำระ → บันทึกการรับเงิน, ปิดบิล, เปลี่ยนโต๊ะเป็น `ว่าง`, แสดงใบเสร็จ (กด `พิมพ์ใบเสร็จ` เพื่อสั่งพิมพ์จริงได้)

## สิ่งที่ปรับปรุงในเวอร์ชันนี้
- ยกเครื่อง UI ทุกหน้าให้สวยและใช้งานง่ายขึ้น (ธีมแดงญี่ปุ่น, ฟอนต์ Noto Thai, การ์ด/เงา/ปุ่มใหม่, รองรับมือถือ)
- หลังเพิ่มลงตะกร้า เด้งกลับหน้าเมนู + แจ้งเตือน + แถบตะกร้าลอย (เดิมเด้งไปหน้าตะกร้าทุกครั้ง ทำให้สั่งหลายอย่างลำบาก)
- เพิ่ม "เวลาที่สั่ง" และ "ผ่านไปกี่นาที" ในหน้าครัว/บริการ/บิลแคชเชียร์
- QR พร้อมเพย์สร้างตามยอดบิลจริง (มาตรฐาน EMVCo PromptPay) สแกนจ่ายได้จริง
  - ใช้ไลบรารีสร้าง QR ที่ฝังมาในโปรเจกต์ (`public/qrcode.min.js`) ไม่ต้องต่ออินเทอร์เน็ต/ไม่พึ่ง CDN
- โหมด QR จ่ายพอดีตามยอด ไม่ต้องกรอกเงินรับ (เดิมบังคับกรอกเงินรับแม้จ่าย QR ซึ่งไม่สมเหตุสมผล)
- หน้าปรับแต่งเมนูแสดงราคารวมแบบเรียลไทม์ + ปุ่มปรับจำนวน (+/−)
- `พิมพ์ใบเสร็จ` สั่งพิมพ์ได้จริง (เดิมเป็นปุ่มเปล่า)
- ตัดกรอบ "แท็บเล็ตควบคุม" ที่ซ้ำซ้อนในหน้าครัว/บริการออก ให้หน้าจอกระชับและใช้งานจริงได้ชัดเจน

ฐานข้อมูล `food.db` จะถูกสร้าง/เติมข้อมูลอัตโนมัติเมื่อรันครั้งแรก
